# 404 — strict tsconfig.server (low-prio)

Модель: sonnet · Волна: 4 · Зависит от: 401, 402 · Статус: отложен

## Контекст

`tsconfig.server.json` собирает сервер с `strict: false` — null/undefined-дыры
не ловятся компилятором.

## Файлы

- `tsconfig.server.json` — изменить (`strict: true`).
- `server/**/*.ts` — чинить ошибки помодульно (route-модули после 401 делают это управляемым).

## Точные изменения

1. Включить strict; собрать список ошибок `npm run typecheck` (или tsc -p tsconfig.server.json).
2. Чинить строго без изменения поведения: явные guard'ы, non-null только с доказательством, никаких `any`-заглушек (допустим `unknown` + narrowing).
3. Если ошибок > ~100 — включать по-флагово (`strictNullChecks` первым) и зафиксировать порядок в этом тикете.

## Acceptance criteria

- `npm run check` зелёный при включённом strict (или зафиксированном подмножестве флагов).
- Ни одного нового `as any` / `!` без комментария-доказательства.

## Не трогать

- Клиентский tsconfig, поведение рантайма.

## Самопроверка

- [ ] Diff не содержит логических изменений — только типовые guard'ы.
